# FaramarzKowsari.github.io

Official website of Faramarz Kowsari.

Live site:

https://faramarzkowsari.github.io/

## Main files

- `index.html` — homepage and SEO metadata
- `styles.css` — responsive visual design
- `robots.txt` — crawler permissions and sitemap location
- `sitemap.xml` — list of indexable site URLs
- `404.html` — custom error page
- `favicon.svg` — browser icon
- `.nojekyll` — serves the static files directly

## Google Search Console

Add this exact URL as a **URL-prefix property**:

https://faramarzkowsari.github.io/

If Google provides an HTML verification file, upload it unchanged to the repository root.
If Google provides a meta tag, paste it inside the `<head>` of `index.html`.
