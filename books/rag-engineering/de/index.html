Originale öffentliche Buchbeschreibung

Englisch

RAG ENGINEERING: From First Principles to Production is a graduate-level engineering reference for building retrieval-augmented generation systems that can justify their answers with inspectable evidence. Rather than treating RAG as a prompt plus a vector database, the book begins with the source contract of the application: what information is authoritative, which user may access it, how freshness and supersession are represented, when the system should abstain, and what evidence must be preserved so a response can later be audited. The opening parts establish information-retrieval fundamentals, lexical baselines, corpus provenance, document parsing, chunking, hierarchy, embeddings, indexes and metadata before advancing to dense retrieval and approximate nearest-neighbor search. The search architecture section develops a progression from sparse and dense retrieval to hybrid search, fusion, reranking and query adaptation, while keeping ranking quality separate from generation quality. Context assembly, grounded answer construction, citation support, abstention, multi-turn and temporal questions, multi-hop retrieval, structured outputs and tool-facing RAG are treated as distinct engineering problems with their own failure modes. The book repeatedly rejects the idea that retrieval automatically eliminates hallucination: an outdated, unauthorized or merely topical passage can be retrieved perfectly and still produce an operationally wrong answer. Evaluation is treated as a first-class scientific discipline. Dedicated chapters cover benchmark design, dataset validity, retrieval metrics, grounded-answer and citation evaluation, ablation studies, significance, replication, continuous evaluation and quality monitoring. Ausgewiesene Lernziele

Englisch

  • Define when retrieval is actually justified and translate broad product requests into measurable source, access, freshness, abstention and evidence requirements.
  • Build and verify a lexical baseline before adding embeddings, and distinguish exact-identifier retrieval from semantic retrieval needs.
  • Prepare document corpora with explicit provenance, governance, parsing, chunking, hierarchy, metadata and lifecycle rules.
  • Compare sparse, dense and hybrid retrieval using independently defined relevance judgments rather than anecdotal examples.
  • Use fusion and reranking as measurable components whose added latency and maintenance cost must be justified by evaluation.
  • Separate retrieval success from generation faithfulness and test context assembly, answer construction, citations and abstention independently.
  • Design benchmarks that include answerable, unanswerable, conflicting, stale, near-duplicate and unauthorized cases instead of only easy demonstrations.
  • Apply retrieval metrics and grounded-answer evaluation correctly, and use ablations and held-out tests to locate regressions and avoid hindsight tuning.
